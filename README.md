# Li Ze / 李泽

Bilingual personal website for https://lize66666.github.io/.

## Preview

Open `index.html` in a browser. No installation or build is needed.
Use the Chinese/English controls to switch language; the choice is remembered.
Use `?lang=en` or `?lang=zh` to choose a language in a shared link.

## Publish on GitHub Pages

1. Create a public repository named `lize66666.github.io` under `lize66666`.
2. Upload `index.html`, `.nojekyll`, and this README to its `main` branch.
3. Open Settings > Pages > Build and deployment.
4. Choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
5. Wait for the Pages deployment to complete. The site URL is
   https://lize66666.github.io/.

## Update

Edit `index.html`. Chinese and English text are stored side by side in
`data-zh` and `data-en` attributes. Contact links use `mailto:`.
The site uses no external fonts, tracking services, or JavaScript dependencies.
Dates, advisors, publications, and degree-completion claims are intentionally
omitted because they have not been provided.
